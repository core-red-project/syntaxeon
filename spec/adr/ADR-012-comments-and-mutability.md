# ADR-012: Comments are spoken asides; mutability is a closed verb pair

Status: **accepted** (2026-11-05)

## Context

Both need a prose-native form that does not disturb rhyme checking.

## Decision

Comments: parenthetical asides, excluded from rhyme and meter. Mutability: `shall be` declares an immutable binding, `shall become` a mutable one; the verb set is closed and versioned (ADR-005).

## Consequences

Charter §2, §13-D8/D9. Exact comment delimiters are fixed in PROSE_GRAMMAR.md.
