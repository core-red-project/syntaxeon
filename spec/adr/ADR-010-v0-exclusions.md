# ADR-010: v0 excludes user records, anaphora and modules

Status: **accepted** (2026-11-05)

## Context

Each adds grammar surface before the core loop is proven.

## Decision

v0 has no user-defined records/types, no anaphora (`it`, `the former`), no modules. Identifiers are common-noun phrases or quoted names, resolved in semantic analysis.

## Consequences

Charter §5, §9, §13-D5/D6.
