# ADR-002: Paradigm: procedural, imperative, expression-oriented

Status: **accepted** (2026-11-05)

## Context

Pure functional semantics would add complexity that does not serve the gimmick.

## Decision

A program is a sequence of acts (declare, change, test, repeat, return). Expressions compose inside prose and yield values. No pure-functional core.

## Consequences

Charter §2, Law 7. Mutability wording is ADR-012.
